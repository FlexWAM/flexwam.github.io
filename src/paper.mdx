<div className="section-heading"><p className="eyebrow">Motivation</p><h2 id="perspective">Flexible visual routing</h2></div>

Multi-camera observations provide complementary information for manipulation. Global and side views provide workspace context, while wrist views reveal local object–target geometry. Their relevance to action prediction varies with the manipulation stage and the current pattern of occlusion.

**FlexWAM learns observation-dependent visual routing for World Action Models (WAMs).** It combines view-specific dynamics modeling with cross-view information exchange and calibrates camera contributions to action prediction using counterfactual view credit.

<div className="section-heading"><p className="eyebrow">Method</p><h2 id="method">Counterfactual-guided visual routing</h2></div>

**Counterfactual (CF) view credit provides an action-grounded signal for learning camera contributions.** Training with the action loss alone can leave routing weights nearly uniform across observations. FlexWAM measures how the action loss changes when each view’s contribution is suppressed, then uses a critic to turn these evaluations into supervision for the router.

<div className="method-columns not-prose">
  <div><span className="method-label">01 · Counterfactual evaluation</span><h3>Measure each view’s contribution</h3><p>Starting from uniform reference gates, mask one visual branch at a time in action attention. Hold model parameters and sampled action noise fixed. The change in action loss measures reliance on that view given the remaining inputs.</p></div>
  <div><span className="method-label">02 · Critic learning</span><h3>Predict normalized view credit</h3><p>Standardize the loss changes across views and train a critic to predict these scores from current-frame visual features. Regression across sampled perturbations encourages the critic to estimate expected normalized CF credit.</p></div>
  <div><span className="method-label">03 · Router calibration</span><h3>Guide routing with CF credit</h3><p>Convert the critic’s predictions into detached soft targets and calibrate the router with a KL loss alongside the action loss. The predicted view weights bias action-to-view attention according to the current observation.</p></div>
</div>

<Figure fullWidth>
  <Picture slot="figure" src={framework} alt="FlexWAM architecture: alternating within-view and cross-view attention, critic-guided router calibration, and view-routed action attention." />
  <Fragment slot="caption">FlexWAM framework. Counterfactual view evaluation measures action-loss sensitivity to masking each visual branch. A critic learns normalized view credit and provides soft targets for router calibration. View-Routed Action Attention uses the resulting observation-dependent weights to modulate visual attention in the action expert.</Fragment>
</Figure>

**View-aware representations support flexible routing.** Each camera stream is encoded independently by a frozen video VAE. Shared video DiT layers alternate within-view and cross-view attention to model local dynamics and integrate complementary context. The router’s log-scaled view gates enter action attention as additive visual-logit biases, preserving relative spatial token preferences within each view.

<p className="research-note"><strong>Training and inference.</strong> Counterfactual evaluations and the critic are used only during training. At inference, future-latent prediction is skipped. The action expert uses current-observation visual features, and routing weights are computed once per observation and reused across all action-denoising steps.</p>

<div className="section-heading"><p className="eyebrow">Real-world evaluation</p><h2 id="experiments">Five tasks across two robot platforms</h2></div>

We evaluate **five manipulation tasks on two robot platforms**, using 100 teleoperated demonstrations per task collected at 30 Hz. The single-arm Flexiv Rizon 4s performs Ethernet cable insertion, L-shaped peg insertion, and round peg insertion. Both peg-in-hole tasks use **0.02 mm clearance**, the most challenging setting in ManipulationNet. The dual-arm AgileX PiPER performs pencil case packing and conveyor sorting.

<Figure fullWidth>
  <Picture slot="figure" src={tasks} alt="Five real-world tasks and camera configurations on the single-arm Flexiv and dual-arm PiPER robots." />
  <Fragment slot="caption">Flexiv uses two fixed cameras and one wrist camera; PiPER uses one global camera and two wrist cameras. Each static task is evaluated in 20 trials at the same randomized initial positions across methods. Conveyor sorting is evaluated on 100 blocks under an identical placement protocol.</Fragment>
</Figure>

### Real-world task success rates

We compare against three WAM baselines—Fast-WAM, OpenWAM, and LaWAM—and the VLA model $\pi_{0.5}$. FlexWAM achieves **77.2%** mean task success with Wan2.2-TI2V-5B and **83.8%** with LingBot-Video-Dense (1.3B). These correspond to gains of **16.4 and 23.0 percentage points** over OpenWAM, the strongest baseline by five-task mean success. The clearest gains occur in precision insertion tasks; on conveyor sorting, FlexWAM (LingBot) matches OpenWAM at 89%.

Pens placement is the mean placement success rate across the two pens and is reported separately. Conveyor sorting success is the proportion of blocks correctly sorted.</p>
