# FlexWAM

Project page for **FlexWAM: Learning Flexible Visual Routing for World Action Models**.

Repository: [FlexWAM/flexwam.github.io](https://github.com/FlexWAM/flexwam.github.io)

## Development

Requires Node.js 24 or later.

```bash
npm install
npm run dev
```

Build the static site with:

```bash
npm run build
```

Pushes to `main` are deployed automatically with GitHub Pages.
